本次任务描述如下：

1、MakeArchiveFileAudioSource 调用 factory.ParseFileFormat 函数时只是用 streamPtr， fileName 参数使用 nullptr;
2、新增三种创建播放列表的方式：
第一种是针对压缩包的：implayer.exe --ml --archive=...  --playlist=...
playlist 参数如果没有指定的话，播放列表默认生成在程序当前的 playlists 目录中，播放列表文件名使用 archive 的名字（不含路径和扩展名）命名；
第二种是针对 CD 光驱的：implayer.exe --ml --cdrom=...  --playlist=...
playlist 参数如果没有指定的话，播放列表默认生成在程序当前的 playlists 目录中，播放列表文件名使用 “CDROM-X” 的名字（X 是 CD 驱动器号）命名；
第三种是针对 CD 光盘映像的：implayer.exe --ml --cdimage=...  --playlist=...
playlist 参数如果没有指定的话，播放列表默认生成在程序当前的 playlists 目录中，播放列表文件名使用 CD 映像文件的名字（X 是 CD 驱动器号）命名；

其中 --archive、--cdrom、--cdimage 和 --folder 子命令是互斥的，不可同时出现。

3、增加一种直接播放压缩包内音频文件的命令行：
implayer.exe --play --archive=...  
这个命令直接打开 archive 参数指定的压缩包，遍历包内的文件，在内存中生成一个 playlist（CArchiveMusic 类型，具体处理方法和播放 CD 与 CD映像的方法类似），然后播放这个 playlist。同样，--archive 与 --filename、--playlist、----cdrom、--cdimage 子命令是互斥的，不可同时出现。
