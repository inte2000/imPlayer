本次任务是创建一个可编译的空的外置编码器项目：

1、给 EncoderPluginOpen 和 EncoderPluginClose 添加一个 uint32_t mediaStreamIdx 成员，表示媒体流索引，默认是 0，表示第一条流。大多数媒体格式也只支持一条流。在 oplugsdk.h 中添加编码器上下文头结构：

typedef struct tagAudioEncodeContextHeader
{
    uint32_t size;
    AudioFormat transFmt;
}AudioEncodeContextHeader;

2、添加对 libsndfile 库的引用，库已经通过 vcpkg 安装，可直接使用。

3、创建 CEncodeControl 对象作为编码器的控制对象，我给出了这个对象的一些公有成员：

class CEncodeControl
{
public:
	CEncodeControl(uint32_t streamFmt);
	
	static void QueryFormatsDefine(std::vector<EncoderFormatDefine>& fmtDesc);
	static void QueryParamtersDefine(uint32_t streamFmt, std::vector<EncoderParamterDefine>& paramDef);
	
	bool Open(CDataStream *pStream, const std::vector<EncoderParamter>& params);
	void Close();
	
	void SetMetaInfo(uint32_t streamIdx, const CMediaTag& metaTags);
	AudioFormat GetTransFormat() const;
	bool Start(const AudioFormat* audioFmt);
	uint32_t Encode(const void* pData, uint32_t frames);
	bool Stop();
};

静态成员 QueryFormatsDefine 用于查询编码器支持输出哪些媒体格式，可参考 WavEncoder.cpp 文件中 s_suppFmts 的定义，将 libsndfile 库支持的输出格式都补充进来。
静态成员 QueryParamtersDefine 查询某个具体的媒体格式需要的参数，可参考 WavEncoder.cpp 文件中  s_suppDefs 的定义。注意， libsndfile 支持多种格式的编码，所以CEncodeControl中的这个定义应该设计成与 streamFmt 有关的表，或者映射关系。
Open 成员函数以指定的编码参数打开编码器对象，用流的方式打开一个 SNDFILE* m_file，paramDef 是指定的编码器参数，CEncodeControl 通过构造函数确定本次的编码格式（streamFmt）。
SetMetaInfo 成员函数用于设置媒体文件的元信息。
GetTransFormat 成员函数返回编码器期望的输入格式，libsndfile 库不支持重采样和多声道的处理，所以这里的采样率和声道数以 open 函数传递的编码参数为准（params 参数包含采样率和声道数），编码格式也由 open 函数传递的编码参数为准，比如输出参数中 bitsPerSample 是 16，则期望的编码格式就是 AudioDataFormat::PCM_S16。因为 libsndfile 库不支持 pack 24，所以当 bitsPerSample 是 24 的时候，也是用 AudioDataFormat::PCM_S32。当  bitsPerSample 是 32 或 64 的时候，要根据 Open 函数的 params 参数是否使用浮点数来判断是 AudioDataFormat::PCM_S32、AudioDataFormat::PCM_S64 还是 AudioDataFormat::Float32、AudioDataFormat::Float64。
Start 和 Stop 控制编码器的开始和结束，Start 函数指定实际输入的 PCM 音频的格式，这个格式通常是根据 GetTransFormat 的结果与解码器协商的结果，Encode 负责将一个批次的 PCM 音频数据用 libsndfile 库提供的接口编码，并输出到 DataStream 中

4、根据 CEncodeControl 提供的成员接口，完成插件导出函数的功能。在 PluginMain.cpp 中添加编码器上下文

typedef struct tagEncoderContext
{
    AudioEncodeContextHeader hdr;
    CMediaTag tags;
    std::unique_ptr<CEncodeControl> encodeCtrl;
}EncoderContext;

Plug_OnInitialize 函数中生成编码器上下文实例，返回这个实例的地址，增加一个导出函数：
void WINAPI Plug_OnRelease(void* ctxhdr);
在这个导出函数中销毁编码器上下文。其他导出函数根据名称与 CEncodeControl 的成员接口对齐。
