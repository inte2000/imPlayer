如果 (m_curPos + size) <= end，则直接从滑动窗口 buffer 中复制 size 字节数据到用户buffer，调整 m_curPos =m_curPos + size，完成读取操作；

如果：(m_curPos + size) > end，则从滑动窗口 buffer 中复制 (end - m_curPos) 字节的数据，同时保存remaind = m_curPos + size - end）作为还需要补充读的数据量。然后调用 ar_entry_uncompress 从archive 中解压缩数据填充滑动窗口，并调整滑动窗口的位置，begin=begin+4MB，end=end+4MB，然后从当前滑动窗口begin位置读取 remaind 字节到 buffer 中，同时将 m_curPos 调整为 begin + remaind，完成读取操作；

3、将 Seek 函数原型调整为 void CArchiveFile::Seek(uint64_t off)，off 的范围就是 [0, 文件原始大小]。Seek 函数遵循以下行为：

（1）当 off 的范围在当前滑动窗口范围 [begin, end] 内时，调整 m_curPos = off，完成 seek 操作；
（2）当 off 的位置 > 窗口范围 end 时，根据 off 计算出 4MB 圆整的的新的滑动窗口范围 [new_begin, new_end]，然后 ar_entry_uncompress 从archive 中解压缩数据，丢弃中间的数据，直到到达 new_begin 位置时将解压缩的数据填充窗口范围，然后调整  m_curPos = off，完成 seek 操作；
（3）当 off 的位置 < 窗口范围 begin 时，根据 off 计算出 4MB 圆整的的新的滑动窗口范围 [new_begin, new_end]，然后调用 ar_seek，到当前 archive 对应文件的开始位置，然后  ar_entry_uncompress 从archive 中解压缩数据，丢弃中间的数据，直到到达 new_begin 位置时将解压缩的数据填充窗口范围，然后调整  m_curPos = off，完成 seek 操作；
